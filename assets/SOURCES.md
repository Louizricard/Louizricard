# Origem dos visuais

- Paleta: #081A2F, #19E6A7 e #FFFFFF, conforme site/assets/css/site.css do [Trabalhei](https://github.com/Louizricard/Trabalhei) e img/logo.svg do [Triagem](https://github.com/Louizricard/triagem-demo).
- Trabalhei: composição com site/assets/screens/desktop-jobs-sm.webp; captura do app com dados de demonstração.
- Triagem: composição com img/03-inicio.png, img/04-chat.png e img/05-cobrancas.png da apresentação pública; capturas do app com dados de demonstração.
- Finnapp e Cofre: cards editoriais próprios, sem capturas de interface. Finnapp tem tela inicial de base e endpoints de autenticação/Pluggy; não se afirma disponibilidade de relatórios ou orçamentos.
- Banner, typing e stack: SVGs próprios. Typing executa uma vez e respeita redução de movimento.
- Estatísticas: REST API pública do GitHub; estrelas apenas de repositórios próprios públicos sem forks.
- Snake: [Platane/snk](https://github.com/Platane/snk), versão fixada no workflow, usando o calendário real de contribuições. O calendário estático permanece no perfil do GitHub.
